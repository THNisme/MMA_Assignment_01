Tạo project: npx create-expo-app ten_du_an --template blank

# Styling
npm install styled-components

# Form
npm install formik yup

# Redux Toolkit
npm install @reduxjs/toolkit react-redux

# Async Storage
npx expo install @react-native-async-storage/async-storage

# Reanimated
npx expo install react-native-reanimated react-native-worklets


Sau đó chạy:
npx expo doctor (hoặc npx expo-doctor)
để kiểm tra tất cả package đã tương thích với Expo 54.0.8 hay chưa.
